# ダブルス スコアシート

バドミントンのダブルスの練習試合で、得点したペアのボタンを押すだけで点数を数えられるWebアプリです。21点を先に取ったペアの勝ちになります。

公開URL：https://doubles-scoresheet.onrender.com

## 使い方

1. トップページでAペアとBペアの名前を入れて「試合を始める」を押す
2. 得点したペアの「＋1」を押す
3. 押し間違えたら「1点戻す」で直前の1点を取り消す
4. どちらかが21点になると勝者が表示される。「新しい試合を始める」で次の試合へ

## しくみ

- Node.js標準の `node:http` でサーバーを作り、画面はPugで作っています。
- 試合の記録はサーバーの中の配列に持ちます。得点は「どちらのペアが取ったか」を順に積み、点数は毎回そこから数え直します。
- 得点・取り消しはPOSTで受け取り、点数画面へリダイレクト（303）します。再読み込みで同じ得点が二重に入りません。
- 勝者が決まったあとの得点は、サーバー側でも受け付けません。

| URL | 内容 |
|---|---|
| `GET /` | 試合開始フォーム |
| `POST /matches` | 試合を作り、点数画面へ移る |
| `GET /matches/:id` | 点数画面 |
| `POST /matches/:id/points` | 得点（`team=A` か `team=B`） |
| `POST /matches/:id/undo` | 1点戻す |

## 手元で動かす

```bash
npm install
npm run dev
```

http://localhost:8000 を開きます。

## 注意

- 公開先はRenderの無料プランです。15分アクセスがないと止まり、次に開いたときに起動まで1分ほどかかります。
- 記録はサーバーの中だけに持つため、サーバーが止まったり再起動したりすると試合の記録は消えます。
